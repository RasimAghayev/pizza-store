# Backend

Django modular monolith. Domain-lərə görə ayrılmış app-lar (identity, customers, restaurants, branches, menu, products, pricing, cart, orders, payments, kitchen, inventory, couriers, delivery, loyalty, notifications, reviews, analytics, audit). Hər modul öz model/serializer/service/repository/API/permission/test strukturuna sahibdir.
