# Accessibility

Pizza Store Platform-un frontend hissəsi (customer-web, management-web, courier-web)
**WCAG 2.2 AA** standartına uyğun olmaq məqsədi daşıyır.

## Hədəflər

- Klaviatura ilə tam naviqasiya.
- Ekran oxuyucuları ilə uyumluluq (semantic HTML, ARIA atributları).
- Kifayət qədər rəng kontrastı.
- Mobile-first, responsive dizayn.
- Form elementləri üçün aydın label və xəta mesajları.

## Status

Frontend hələ implementasiya olunmayıb (Phase 7). Accessibility yoxlamaları Angular test
infrastrukturu qurulduqdan sonra CI pipeline-a əlavə olunacaq (avtomatlaşdırılmış axe-core
yoxlamaları + manual audit).

## Bildiriş

Accessibility problemi aşkar etsəniz, GitHub Issues-də "Bug Report" şablonu ilə bildirin.
